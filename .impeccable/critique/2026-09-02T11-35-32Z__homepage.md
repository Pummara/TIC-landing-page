## Design Specificity Verdict

Grounded, not template-interchangeable — manifest rows not cards, ticket-stub notch, unlabeled route map, gold spent only as full-section fill or precise marks, real bilingual craft (weight-compensation rules, independently-written TH/EN copy). Gap: strongest trust logos (AOT/PTT/ThaiBev/GIZ/BEM) exist unused while a less-recognizable set ships instead.

CLI scanner (`detect.mjs`) degraded — missing `htmlparser2`/`css-select`/`css-tree`/`domutils`, so its `[]` result is not meaningful. Live in-browser detector found real signal: `line-length` ~123 chars/line on Services descriptions (corroborates DESIGN.md's documented no-max-w decision), `all-caps-body` matching Contact's uppercase email value, and a `low-contrast` white-on-gold reading investigated and attributed to a likely detector false positive (Button.tsx's outline-light variant never actually renders white text and gold fill in the same frame — text flips to ink in the same state transition that paints the gold sweep). `overused-font`/`marquee` findings read as low-signal for a deliberate single-typeface, reduced-motion-respecting site.

## What's Working
1. No-card manifest system is a disciplined domain interpretation, verified against DESIGN.md with zero violations found.
2. Sweep/Ruled-Underline hover system treats keyboard and mouse identically.
3. Bilingual craft goes past string-swapping — independently-written copy in both languages.

**[P1] Trust Bar restates Hero with zero new information.** Same four adjectives, different words; hard credentials don't land until section five. Fix: cut Trust Bar or replace with quantified content; move credentials up. → `/impeccable layout`

**[P2] Static, dateless hours, no live status, phone-first conversion path.** No days-of-week, no computed open/closed. Fix: add days at minimum; ideally live status vs. Bangkok time. → `/impeccable clarify`

**[P2] Services description lines ~123 chars/line — detector-confirmed.** Direct tradeoff of the documented no-max-w decision. Fix: cap the text itself via `ch` units without reopening the wasted-space problem. → `/impeccable typeset`
